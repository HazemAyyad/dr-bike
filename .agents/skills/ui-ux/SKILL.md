# UI/UX Engineering Skill

Identify: Trigger when modifying CSS, components, templates, or page layouts.

## Core Rules

- Avoid generic placeholders or raw unstyled components.
- Enforce accessibility (WCAG AA compliance) with correct aria-labels.
- Adopt a strict design system (consistent spacing scale, defined type hierarchy, and cohesive color palette).
- Always use premium micro-interactions and transitions rather than sudden element appearances.
